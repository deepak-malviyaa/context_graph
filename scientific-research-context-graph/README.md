## Quick Start

```bash
# Install dependencies
make install

# Neo4j Aura is already running in the cloud
# Credentials are in your .env file

# Seed sample data
make seed

# Start the application
make start
```

- **Backend:** http://localhost:8001
- **Frontend:** http://localhost:3001
- **Neo4j Aura Console:** https://console.neo4j.io

## Domain: Scientific Research

- **Person** — PERSON
- **Organization** — ORGANIZATION
- **Location** — LOCATION
- **Event** — EVENT

## Agent Tools

The AI agent has access to the following domain-specific tools:

- **search_researcher** — Search for researchers by name, specialization, or institution
- **citation_network** — Explore citation relationships for a paper
- **dataset_usage** — Find which papers and experiments have used a specific dataset
- **grant_analysis** — Analyze grant funding status and associated research output
- **experiment_results** — Query experiment details and outcomes
- **list_researchers** — List researcher records with optional limit
- **get_researcher_by_id** — Get a specific researcher by ID with all connections
- **execute_cypher** — Run ad-hoc Cypher queries
- **get_schema** — View the graph schema

## Agent Framework: LangGraph

This project uses [LangGraph](https://langchain-ai.github.io/langgraph/) with `@tool` decorators and `create_react_agent()`. The agent is a compiled graph that manages tool execution state. Supports full streaming via `graph.astream_events()`.

Requires `GROQ_API_KEY` and `GROQ_MODEL` in `.env` (uses `langchain-groq`). Any Groq tool-calling model works; defaults in `.env.example` use `openai/gpt-oss-120b`.

See `backend/app/agent.py` for the full implementation.


## Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

| Variable | Description |
|----------|-------------|
| `NEO4J_URI` | Neo4j connection URI |
| `NEO4J_USERNAME` | Neo4j username |
| `NEO4J_PASSWORD` | Neo4j password |
| `GROQ_API_KEY` | Groq API key for the AI agent (required) |
| `GROQ_MODEL` | Groq model id, e.g. `openai/gpt-oss-120b` (required, read from env — never hardcoded) |
| `GROQ_URL` | Groq OpenAI-compatible base URL (default: `https://api.groq.com/openai/v1`) |
| `OPENAI_API_KEY` | Optional: OpenAI embeddings for conversation memory |
| `ANTHROPIC_API_KEY` | Optional: not required when using Groq |
| `SESSION_STRATEGY` | Memory session strategy (per_conversation, per_day, persistent) |
| `BACKEND_PORT` | Backend port (default: 8001) |
| `FRONTEND_PORT` | Frontend port (default: 3001) |

## Troubleshooting

### Neo4j Connection Errors

**"Neo4j is unavailable" on all endpoints**
- Verify your `.env` file has correct `NEO4J_URI`, `NEO4J_USERNAME`, and `NEO4J_PASSWORD`
- Run `make test-connection` to validate credentials
- Ensure your Aura instance is running and the URI starts with `neo4j+s://`

**Extra variables in `.env`**
- The backend accepts extra environment variables, so standard Neo4j Aura `.env` exports (with `NEO4J_DATABASE`, `AURA_INSTANCEID`, etc.) work without editing

### Backend Issues

**Port already in use**
- Change `BACKEND_PORT` in `.env` (default: 8001)
- Kill existing process: `lsof -ti:8001 | xargs kill`

**API key not set**
- Set `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` in `.env` depending on your agent framework

### Frontend Issues

**Build errors after `npm install`**
- Delete `node_modules` and `package-lock.json`, then run `npm install` again
- Ensure Node.js 18+ is installed
